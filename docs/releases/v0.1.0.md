# NexusMind v0.1.0

NexusMind `0.1.0` is the first public release of the local-first KnowledgeBase
runtime. It ships a Windows portable archive, Python distributions, a CLI, a local
desktop interface, and a Python API.

## Highlights

- Register local file and directory Knowledge Sources, then explicitly synchronize
  them into canonical Knowledge state.
- Search offline with the default Unicode/CJK BM25 lexical backend.
- Opt into Semantic retrieval, Hybrid-RRF fusion, and bounded reranking backends.
- Generate query answers with validated citations limited to passages supplied to
  the answer model.
- Inspect canonical state and use retrieval diagnostics to understand lexical,
  semantic, fusion, and reranker stages.
- Retain immutable document version history while exposing only current documents
  to synchronization, retrieval, and answers.
- Reopen a strict manifest/SQLite persistence v1 KnowledgeBase across processes.
- Use the Windows portable runtime without installing Python, or install the wheel
  or sdist for the `nexusmind` and `nexusmind-kb` entrypoints and Python API.

## First release constraints

- Local text inputs must use strict UTF-8 encoding.
- Supported file types are `.txt`, `.md`, and `.markdown`.
- There is no Git source adapter and no GitHub ingestion.
- There is no background synchronization or file watcher; synchronization is
  explicit.
- There is no cloud-hosted KnowledgeBase.
- Derived chunks, embeddings, and retrieval indexes are rebuilt rather than persisted.
- PDF/Office parsing, installers, updaters, services, and cloud features are not
  included in this release.
